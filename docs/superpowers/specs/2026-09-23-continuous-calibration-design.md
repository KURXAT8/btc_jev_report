# 持續學習與機率校準

使用者已要求實作內部持續學習與機率校準。目的為改善未來預測機率的可靠度；不以提高 confidence 數字或宣稱提高命中率為驗收。

## 方法與邊界

第一版採單一溫度參數，比類別專屬校準器更省樣本，且不改變最大機率方向。參數小於 1 可集中機率，大於 1 可降低過度自信；是否使用由獨立較晚資料決定。直接修改 Jev 提示詞、訓練其權重、新增其他模型 API 與新聞對照實驗均不屬本次實作。

`CALIBRATION_MODE=auto` 預設自動學習及有條件採用；`shadow` 學習及保存候選但不影響郵件；`off` 停止學習並使用原始機率。無額外 API 請求或相依套件。

## 資料與時間規則

依 horizon、model、rules_version、label_version、config_hash 分組。各組每個台北週一 00:00 截止只建立一次不可變評估；重跑或晚到結果等下週再學習。只使用過去 365 天、在截止前已建立、到期、已取得結算且實際寫入時間嚴格早於截止的原始預測。每個結算版本都保存觀測時間；追溯更正不會改變較早週截止使用的樣本。舊資料升級時，原先無法得知觀測時間的結算保守地標記為資料庫升級時間。每個來源時間只保留一筆，不混用模型版本。

最後 60 筆為驗證集；更早資料為訓練集（至少 120 筆）。兩者預測起點隔離至少 7 天，且訓練的 due_at、settled_at 均早於驗證起點。訓練每類至少 10 筆、驗證每類至少 5 筆。不足時只保存暖機狀態。

從固定溫度集合選訓練 log loss 最小的參數；驗證資料絕不參與擬合或重擬合。採用須同時滿足：Brier 至少降低 0.005、log loss 不變差、至少 8 個 7 天驗證區塊，固定種子的 500 次區塊 bootstrap 差值 95% 上界小於 0。這是保守工程門檻，並非反覆週檢定下的統計保證。

## 持續運作、保存與回退

每日 prepare 保存原始預測後，以本機每週快取評估，凍結當天應用結果。另提供離線 `learn` 與 `learning-status` 命令。原始 Prediction/distribution/confidence、歷史 MIME、週報皆不覆寫。學習失敗時凍結當日原始機率與郵件；之後重啟不會用較晚校準改寫已準備報告。

新增 calibration_runs 與 calibrated_forecasts 表。保存評估截止、訓練／驗證樣本 ID 與結算版本、參數、指標、政策版本、狀態、原因；每日記錄原始／候選／實際採用機率與採用時間。最新評估未通過時回原始，不繼續使用舊的通過版本。過期或錯誤也回原始。

監測最近 90 天同組真正前瞻套用的校準結果；至少 30 筆時，若 Brier 比原始差超過 0.01 或 log loss 差超過 0.02，暫停採用並回原始。新資料與每週評估仍持續；舊退化資料離開窗口後才有機會重新採用。監測不得讀取當日資料截止之後才知道的結果。

## 呈現與驗收

只有實際採用時，日報同時明確標示 Jev 原始機率與本機校準機率；Jev confidence 保持原義。週報內部增加實際套用樣本的成對原始／校準指標，不把回溯驗證冒充前瞻成績。狀態指令呈現暖機、通過、未通過、退化、停用與樣本數。

測試需覆蓋溫度變換、零機率、分組、未到期與晚到資料、跨切分邊界、類別不足、較晚驗證失敗、每週冪等、版本不可变、凍結後重啟、off/shadow/auto、前瞻退化回退、原始資料不變、郵件標示與週報比較。全程離線驗證，不寄信。
